# Hypo review samples

Sample files for reviewing Hypo on the Mac App Store.

`Hypo-test-card.dmg` (in the latest release) is a disk image laid out like a camera memory card: 5 photos from a Fujifilm camera, each as a JPEG + RAW (RAF) pair, in `DCIM/100_FUJI`. Double-click it to mount; it appears as a card named `HYPO_TEST`.

Hypo only reads from cards, so nothing on the image is ever modified.
